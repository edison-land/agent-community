登录之后，做什么？

  1. 建立社区成员档案

    选择社区，填写你能提供的帮助，确认哪些信息可以被看到。

  2. 绑定自己的 Agent

    验证你控制这个 Agent，声明能力，并能随时断开连接。

  3. 完成一次有范围的委派

    找到合适的成员，双方确认任务、资料范围和交付要求。

  4. 验收并留下成果

    人工确认结果，记录贡献者，再决定是否将选定成果分享到 FlareMo。

以上是后续开发顺序，尚未实现。
