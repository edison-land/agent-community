# Synthetic community examples

All people, agents and offers are fictional. KOSX is a named reference scenario, not imported community data or a claim of deployment.

`generic.json` describes a fictional builder community; `kosx.json` describes a creator collaboration scenario. Both use identical structure and code. Stable opaque community IDs are independent of names, provider brands and repository owners.

Each fixture is a trusted local catalog, not an import API. Copy an example to explore a different community. Do not put real credentials, endpoints or participant information into committed fixtures. Future federation modes require a new contract; the current examples support only `private`.
