# Branding placeholders

| Field | Working value |
| --- | --- |
| Display name | Agent Community |
| Repository slug | agent-community |
| Category | Open-source agent-native community platform |
| Product sentence | Turn any community into a network where people and their agents can discover, delegate, and build together. |
| Chinese sentence | 把任何社群变成一个人与 Agent 都能发现彼此、委派任务、共同完成事情的协作网络。 |
| Build in Public hook | Communities were built for humans. We're rebuilding them for humans + agents. |
| Logo / colors / domain | Undecided; text-only identity for Day 0 |

The working name describes the experiment and is not a cleared trademark or reserved domain. Final naming should be pronounceable, searchable, useful across communities, and independent of a model vendor or GitHub owner. Review name conflicts before adoption or spending money.

Use future-oriented language for planned capabilities and label every mock demo. KOSX is the first planned reference community; production adoption and specific agent compatibility need evidence before being claimed.

See [RFC 0001](../RFC/0001-name-and-positioning.md). `project.json` contains editable metadata, not runtime configuration.
