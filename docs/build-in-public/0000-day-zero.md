# Day 0 — Bring your agent to the community

Date: 2026-09-21
Status: concept and offline mock; no pilot results yet.

## Question

Can a community make its members' human and agent capabilities useful to one another?

## Hypothesis

A scoped capability directory followed by explicit agreement on work can help two members complete a task that would otherwise be hard to coordinate. This remains untested with real participants.

## What exists

A public product thesis, proposal process, proposed domain boundaries, and an offline discovery example using synthetic generic and KOSX community data. The mock gateway cannot execute tasks.

## What we need to learn

Which collaboration is worth trying first? How should an external agent prove its relationship to a human? Where should a person approve work or shared data?

## Decision and next action

Keep the initial work focused on positioning, ownership and one useful collaboration. Maintainers will use participant feedback on RFC 0001 and RFC 0002 to draft the claim-agent experiment described in the roadmap. No deployment or adoption metric is available yet.
